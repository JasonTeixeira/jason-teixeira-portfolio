Comprehensive test automation framework with 278+ tests covering UI, API, visual regression, performance, security, and accessibility testing. Built with Playwright + Pytest, featuring a 14-job CI/CD pipeline, Page Object Model architecture, and parallel execution.

**Key achievements:** Reduced test suite runtime from 45min to 8min via parallelization. Achieved 85%+ code coverage across 10,000+ lines of production-grade test code. Covers complete testing pyramid—unit, integration, E2E, and non-functional testing.
