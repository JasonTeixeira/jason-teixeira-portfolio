Appium-based mobile automation framework supporting both iOS and Android platforms. Features driver manager handling platform differences, base page with mobile-specific gestures (swipe, scroll, tap, long-press), configuration management via YAML, and utilities for common mobile interactions like hiding keyboard and backgrounding apps. Built to handle real-world mobile testing challenges across different devices and OS versions.
