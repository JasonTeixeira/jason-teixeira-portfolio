OWASP-focused security testing framework for identifying common web vulnerabilities. Tests for SQL injection, XSS (cross-site scripting), missing security headers, and open redirects. Features severity-based reporting (HIGH/MEDIUM/LOW), comprehensive documentation with legal warnings and responsible disclosure guidelines. Built for ethical security testing with practical remediation advice for each vulnerability type.
