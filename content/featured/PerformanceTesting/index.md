Locust-based performance testing framework with realistic user behavior modeling and multiple test scenarios (load, spike, stress, endurance). Features JWT authentication simulation, configurable user patterns, CLI tool for easy execution, and comprehensive HTML reporting. Built to identify bottlenecks and capacity limits before they impact production.
