Web automation framework with 118+ tests using Playwright + Page Object Model. Multi-browser support (Chromium, Firefox, WebKit), parallel execution via pytest-xdist, auto-screenshots on failure. Reduced execution time from 15 minutes to 5-7 minutes with 4-worker parallelization. Clean architecture with test/page object/utility separation.
