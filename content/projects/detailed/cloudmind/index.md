## Overview

Multi-cloud cost tracking and security scanning dashboard with AI-powered optimization recommendations. Integrates with AWS, Azure, and GCP to provide unified visibility across cloud providers.

## Key Features

- Multi-cloud cost tracking (AWS/Azure/GCP)
- Security vulnerability scanning
- OpenAI GPT-4 cost recommendations
- Next.js 14 frontend + FastAPI backend
- TimescaleDB for time-series cost data

## What Was Hard

AWS Cost Explorer API rate limits (1 req/5s), TimescaleDB setup complexity, OpenAI API costs ($50/month), and Three.js 3D visualization learning curve.

## Results

Used for personal AWS account (~$100/month spend). Cost dashboard provides useful spending visibility over time.
