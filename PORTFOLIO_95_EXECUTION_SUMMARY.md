## 💡 PRO TIPS

**For Diagrams:**
- Keep them simple and clean
- Use consistent colors (your theme: silver/platinum)
- Label everything clearly
- Export at 2x resolution for crisp display

**For Charts:**
- Use your brand colors
- Make axes clear
- Add data labels
- Keep it professional (not flashy)

**For Code Screenshots:**
- Dark theme always
- Zoom to 150% before screenshot
- Crop tightly
- Add subtle shadow for depth

**For Project Screenshots:**
- If you don't have live system, mockups are OK
- Annotate to explain what's shown
- Show the impressive parts
- Quality > having every screenshot
